# Product Brief — DevScout

## Problema

CTOs precisam identificar desenvolvedores open source qualificados, mas os sinais disponíveis no GitHub são fragmentados, difíceis de comparar e sujeitos a interpretações superficiais.

## Solução

O DevScout consolida dados públicos do GitHub, calcula métricas explicáveis e fornece uma interface privada de busca, comparação e acompanhamento de candidatos.

## Público

### Primário

- CTO
- Head of Engineering
- Engineering Manager
- Tech Recruiter técnico

### Secundário

- avaliadores convidados;
- líderes técnicos;
- pessoas autorizadas pelo owner da organização.

## Proposta de valor

- descoberta orientada por evidências;
- ranking explicável;
- filtros técnicos relevantes;
- comparação consistente;
- colaboração privada;
- histórico de decisões;
- gestão de acesso.

## MVP

- autenticação;
- organização inicial;
- owner e membros;
- convite de usuários;
- busca por desenvolvedor;
- sincronização de perfil GitHub;
- listagem com filtros;
- cálculo de score;
- perfil detalhado;
- favoritos;
- notas;
- tags;
- status de pipeline;
- auditoria básica;
- testes;
- README de instalação;
- deploy demonstrável.

## Fora do MVP

- billing;
- múltiplos planos;
- importação massiva irrestrita;
- contato automatizado;
- scraping fora da API oficial;
- IA generativa para avaliação automática;
- banco separado por tenant;
- ATS completo;
- extensão de navegador.

## Indicadores de sucesso

- usuário consegue encontrar candidatos por linguagem e localização;
- score é compreensível e auditável;
- nenhuma organização acessa dados privados de outra;
- sincronização respeita rate limit;
- busca e filtros respondem adequadamente;
- fluxos críticos possuem testes automatizados.
